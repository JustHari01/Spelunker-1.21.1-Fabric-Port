# Changelog

## 1.5.3+1.21.1.unofficial.1

- Unofficial Fabric port for Minecraft 1.21.1.
- Migrated configuration, potion, loot, rendering, and networking code to the 1.21.1 APIs.
- Bundled Hjson Java 3.1.0 so the existing Hjson configuration format remains available.
- Updated the player-connect mixin for the 1.21.1 `ConnectedClientData` parameter; a clean dedicated server now starts and initializes a world with this build.
